# 📖 Reading Log · Multi‑Dimensional Journal

> An offline‑first tool for logging books and films with 14 custom anchors (scent, place, memory, emotion…), cover image support, and full local storage.

**[🔗 Live Demo]([file:///C:/Users/%E5%B7%A7%E5%85%8B%E5%8A%9B/Desktop/mvp/reading-log.html](https://chocolatewin.github.io/PM-Portfolio/#-run-locally))**  

## ✨ Features

- 📚 **Two record types** – Books and films, each with its own icon & statistics.
- 🖼️ **Cover images** – Upload from gallery, thumbnails displayed on the home list.
- 📝 **14 multi‑dimensional anchors** – Scent, Place, Memory, Network, Sound, Temperature/Weather, Emotion, Object, Time/Moment, Color/Visual, Excerpt/Line, Character, Question/Confusion, Creative Inspiration.
- ✍️ **Mini review** – Optional free‑text area for complete output.
- 💾 **Local storage** – All data stays in browser localStorage; no backend needed.
- 👤 **Profile page** – Custom avatar (compressed) and nickname.
- 📱 **Mobile‑first** – 393px width, rounded cards, touch‑friendly.
- 🔍 **Filter & stats** – Filter by type, show total counts of books and films.

## 🛠️ Tech Stack

- Pure HTML / CSS / JavaScript (no external libraries)
- LocalStorage persistence
- Responsive layout, works on mobile & desktop browsers

## 🚀 Run Locally

1. Download `index.html`.
2. Double‑click to open with any modern browser (Chrome/Edge/Safari).
3. Start logging your first book or film.

## 🌐 Deploy to GitHub Pages

1. Push the code to a GitHub repository.
2. Go to `Settings` → `Pages`.
3. Source: `Deploy from a branch` → `main` branch, `/ (root)` folder.
4. Save. After 1 minute your site will be live at `https://yourusername.github.io/repo-name/`.

# 📖 阅读记录 · 多维笔记

> 一款离线优先的阅读与观影记录工具，通过 14 个自定义锚点（气味、地点、回忆、情绪等）捕捉你的感性输出，并支持封面图片上传、本地持久化存储。

**[🔗 在线 Demo]([https://yourusername.github.io/PM-Portfolio/](https://chocolatewin.github.io/PM-Portfolio/#-run-locally))**  

## ✨ 功能特性

- 📚 **双类型记录** – 支持「书」与「影」两种记录类型，独立图标与统计。
- 🖼️ **封面图片** – 从相册上传封面，首页列表自动展示缩略图。
- 📝 **14 个多维锚点** – 气味、地点、回忆、网络、声音、温度/天气、情绪、物件、时间/时刻、颜色/视觉、书摘/台词、人物/角色、疑问/困惑、创意灵感。
- ✍️ **小书评** – 可选的完整输出区域，支持多行文本。
- 💾 **本地存储** – 所有数据保存在浏览器 localStorage 中，关闭页面不丢失。
- 👤 **个人主页** – 自定义头像（压缩存储）与昵称。
- 📱 **移动端适配** – 宽度 393px，圆角卡片，手势友好。
- 🔍 **筛选与统计** – 按类型筛选记录，首页底部显示总记录数、书/影数量。

## 🛠️ 技术栈

- 纯原生 HTML / CSS / JavaScript
- LocalStorage 数据持久化
- 无任何外部依赖（零 npm / 零构建）
- 响应式布局，适配手机与桌面浏览器

## 🚀 本地运行

1. 下载 `index.html` 文件。
2. 双击用浏览器打开（推荐 Chrome / Edge / Safari）。
3. 开始记录你的第一本书或电影。

## 🌐 部署到 GitHub Pages

1. 将代码推送到 GitHub 仓库。
2. 进入仓库 `Settings` → `Pages`。
3. Source 选择 `Deploy from a branch`，分支 `main`，文件夹 `/ (root)`。
4. 保存，等待 1 分钟，即可通过 `https://你的用户名.github.io/仓库名/` 访问。
